# Keep Muscle by Prime Vitality

Web app for GLP-1 muscle preservation.

## Live URL
https://keep-muscle-patrick-757d.vercel.app

## What belongs in this repo
- `index.html` — the app
- `accepted_workout_videos/` — compressed demo clips
- `vercel.json` — static hosting

After those files are in this repo, Vercel can serve the app and the videos together.
